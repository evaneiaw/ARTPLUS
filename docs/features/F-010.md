# F-010 — Trapping

## 1. Resumo

A funcionalidade Trapping no módulo PDFObjectLayer.dll fornece um checkbox na toolbar do ArtPro+ que alterna o estado de trapping do documento. Não existe diálogo de parâmetros (largura, choke, spread) exposto; a alteração afeta flags de documento e anotações GOAnnotTrapNet no modelo de dados PDF. A evidência comportamental (CAP-20261127-01) confirma a existência do checkbox e a ausência de interface de parâmetros.

## 2. Entrada

- **Documento:** PDF/Abrido no ArtPro+ v24.03.10017. Não há restrição de tipo de página observada.
- **Seleção:** nenhuma seleção de objeto ou área é necessária; a funcionalidade afeta o documento como um todo.
- **Camadas:** não há requisito de camada comprovado; opera no nível do modelo de dados do documento (GODocument flags e anotações).
- **Pré-condição:** documento aberto com suporte a cores de processo/DeviceN (implícito pela presença de funções de flag de trap no módulo). Se o documento não tiver essas características, o checkbox não tem efeito observável.

> **Inferência** (fonte: GHIDRA strings `?GetInfoDictTrappedFlag@GODocument@@`, `?SetTrappedFlag@GODocument@@`, `??0GOAnnotTrapNet@@`): as funções de flag de trap e a anotação GOAnnotTrapNet indicam que o módulo dá suporte a trapping para documentos que usam espaços de cor DeviceN/NChannel ou cores de processo. Não há evidência de limitação a tipos de documento específicos.

## 3. UI

- **Caminho:** Toolbar — checkbox rotulado "Trapping" na linha de botões funções (observado em x=1271, y=47).
- **Tipo:** CheckBox, acessível via UI Automation (name="Trapping", type=CheckBox).
- **Atalho:** nenhum observado.
- **Comportamento ao clicar:** alterna o estado de trapping do documento; não abre diálogo modal ou campo de parâmetros (largura, choke, spread, cor).
- **Menu Prepress > Trapping:** não acessível via UI Automation (dropdown custom-drawn); itens não enumeráveis. Atalho Alt+P foca menu bar, mas o sub-item Trapping não é revelado.

> **Observação**: O CAP observa apenas o checkbox toolbar; não há evidência de menu/path Parâmetros de trapping. O resto é inferência marcada como tal.

## 4. Regras

R1. Clicar no checkbox "Trapping" na toolbar alterna o estado de trapping do documento aberto (observado via CAP-20261127-01).

R2. A alteração de estado não abre diálogo modal nem expõe campos de parâmetros (largura, choke, spread, cor). O estado visual do checkbox é atualizado (checked/unchecked) (observado via CAP).

R3. As funções `GetInfoDictTrappedFlag`, `SetTrappedFlag`, `GetTrappedFlag`, `GetXMPTrappedFlag` (evidência estática GHIDRA em PDFObjectLayer.dll) leem/escrevem flags de trap no dicionário de informação do documento e/ou metadados XMP (inferência marcada: fonte GHIDRA strings).

R4. A classe `GOAnnotTrapNet` (evidência estática: construtores `??0GOAnnotTrapNet@@AEAA@AEBVGADict@@@Z`, `??1GOAnnotTrapNet@@UEAA@XZ`, RTTI presente) representa a anotação de rede de trap no documento; sua criação/gerenciamento é interno ao módulo (inferência marcada: fonte GHIDRA RTTI strings).

R5. Não há parâmetros de trapping observáveis (largura, choke, spread) na UI; o comportamento de trapping, se houver, é ativado/desativado pelo checkbox sem configurações adicionais (observado via CAP — "no trapping-specific dialog discovered").

## 5. Exceções/Erros Observados

- Nenhum erro ou mensagem observado ao clicar no checkbox "Trapping".
- Se o documento não tiver suporte a trap (ex.: documento RGB simples sem DeviceN/NChannel), o checkbox alterna estado mas não produz efeito visual ou de dados observado.
- Menu Prepress > Trapping não acessível via UI Automation (dropdown custom-drawn); tentativa de acesso via Alt+P também não revelou items. Isso não impede a funcionalidade do checkbox toolbar.
- Fallback: campos "Separations" e "Marks" no painel direito não abrem diálogos de trapping; apenas rótulos de navegação.

## 6. Saída

- **No documento (persistente):** flags de trap são gravadas no dicionário Info do documento e/ou metadados XMP (GetInfoDictTrappedFlag / SetTrappedFlag / GetXMPTrappedFlag). Anotação GOAnnotTrapNet pode ser adicionada ao documento como objeto de anotação PDF.
- **Visual (apenas UI):** checkbox "Trapping" na toolbar alterna entre estados checked/unchecked, refletindo o estado de trapping do documento.
- **Não gravado no PDF:** parâmetros de trap (largura, choke, spread) nem efeitos de sobreposição visual são escritos nem observados sem etapa comportamental adicional.

> **Inferência** (fonte: GHIDRA `?GetInfoDictTrappedFlagValue@GODocument@@AEBA_NAEAVGBuffer@@@Z`, `?SetInfoDictTrappedFlagValue@GODocument@@AEAAXAEBVGBuffer@@@Z`): as funções de valor de flag indicam que o estado de trap pode ser gravado/ lido do buffer do documento; não há evidência de que esses valores influenciem renderização visual sem operação downstream.

## 8. Em aberto

1. **Efeito visual de trapping**: o checkbox alterna estado, mas não há evidência de que o trapping se traduza em sobreposição visual (linhas de trap) na GUI sem operação downstream. *Pergunta:* o ArtPro+ renderiza traços de trap quando a flag está setada? *Onde obter:* captura comportamental na v24.03.10017 com medição visual ou inspeção de PDF de saída.
2. **Função das flags de trap**: GetInfoDictTrappedFlag / SetTrappedFlag gravam no dicionário Info — qual é o efeito dessas flags na leitura/renderização de PDFs consumidores? *Pergunta:* verificar se a flag altera comportamento em leitores PDF padrão. *Onde obter:* teste de roundtrip PDF na v24.03.10017.
3. **Integração GOAnnotTrapNet**: a anotação GOAnnotTrapNet é criada internamente — qual é o seu ciclo de vida (quando é removida, clonada, persistida)? *Pergunta:* medir persistencia da anotação em save/reload ciclo. *Onde obter:* captura comportamental na v24.03.10017.
4. **Menu Prepress > Trapping**: dropdown custom-drawn não acessível via UIA. *Pergunta:* existe atalho de teclado ou caminho de menu alternativo para abrir painel de parâmetros de trap? *Onde obter:* inspeção UIA avançada ou captura de tela com ferramentas de automação.
5. **Documentos sem DeviceN**: o checkbox tem efeito em documentos que usam apenas cores de processo RGB/CMYK? *Pergunta:* testar em documento sem espaços DeviceN/NChannel. *Onde obter:* GUI na v24.03.10017.
6. **Valor default de flag de trap**: não medido. *Pergunta:* qual o valor default da flag de trap ao abrir um novo documento? *Onde obter:* inspeção de metadados XMP ou dicionário Info de documento novo.
7. **CAP negativo confirma ausência**: `CAP-BLOCKED-*` não conta como evidência comportamental. *Pergunta:* se não houver CAP positivo, o que se pode afirmar sobre a existência de UI de trapping? *Onde obter:* política de evidência em AGENTS.md §12.
