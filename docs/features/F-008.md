# F-008 — Color Management / ICC

## 1. Resumo

O módulo `ColorManipulationLayer.dll` fornece o subsistema de gerenciamento de cores do ArtPro+ v24.03.10017: inicialização singleton, cache de perfis ICC, resolução de perfil ativo por tipo/categoria, definição de perfil por nível (stack) e conversão de cor via callback. A API é exposta via `GCColorManipulation::GetInstance()` após `GCColorManipulationLayer::Initialize()`. A UI expõe painel lateral "Colors" (separações/perfil), `Object > Recolor...`, `Object > Remove Color Profile ▸` e `Prepress > Convert Separations With ▸`; na v24.03.10017 **não existe** menu dedicado de gerenciamento de cor.

## 2. Entrada

- Documento aberto com pelo menos uma página.
- Camada de cor válida (objetos com espaço de cor definido: CMYK, RGB, Lab, Gray, DeviceN, spot).
- Pré-condição: `Initialize()` já chamado (retornou `true`); caso contrário, `GetInstance()` lança exceção interna.
- Unidades do documento em mm ou pt; conversões internas operam em valores normalizados (0.0–1.0 ou 0–255 por canal).

O backend (`ColorManipulationLayer.dll`) centraliza a API de ICC/Color Management. Fonte: CAP-20261121-01/02 (menus Object/Prepress/ribbon), `rag/evidence/F-008/manifest.json` (SHA-256 do backend).

## 4. Regras

1. **Inicialização**  
   `GCColorManipulationLayer::Initialize()` executa uma única vez (padrão singleton com contador de reentrância `sInitialized`):  
   a. Se `sInitialized > 0`, incrementa e retorna `true`.  
   b. Chama `GCICCProfileCache::CreateInstance()`.  
   c. Chama `FUN_180027c40()` (inicialização subsistema lcms/device-link) — deve retornar `true`.  
   d. Chama `FUN_1800269b0()` (inicialização Pantone/color libraries) — deve retornar `true`.  
   e. Chama `InitializeStrings()` (carrega mensagens de erro do .rdata).  
   f. Chama `InitializeXYZProfile()` (registra perfil XYZ padrão `Enfocus XYZ Profile.icc`).  
   g. Define `sInitialized = 1` e retorna `true`. Qualquer falha em c/d aborta com `false`.

2. **Acesso ao singleton**  
   `GCColorManipulation::GetInstance()` retorna referência ao `sInstance` estático. É o único ponto de entrada público; todas as operações de cor passam por esta instância.

3. **Definição de perfil ICC por nível**  
   `SetLevelICCProfile(ColorType ct, GSharedObject<GCICCProfile> profile, bool replace, CategoryType cat)`  
   a. Se `cat == 0` (Default), usa array de perfis em `this + 0x20`; senão usa `this + 0x8` (Override/DeviceLink/Proof).  
   b. Índice no array derivado de `*(int*)(pGVar1 + 0xc)` (contador de nível atual).  
   c. Chama `FUN_1800161c0(perfil_ptr, ct, profile, replace)` para efetivar a definição.  
   d. `replace == true` substitui o perfil existente no nível; `false` empilha (push) novo nível.

4. **Resolução de perfil ICC ativo**  
   `GetActiveICCProfile(ColorType ct, bool useCache, CategoryType cat) -> GSharedObject<GCICCProfile>`  
   a. Se `useCache` em {0,1,2,3} (valores 0–3), tenta retornar cache em `this + 0x38`; se NULL, lança `GCSimpleException(0x124f85)`.  
   b. Senão, itera array `GCColorLibInfo` (base `this + 0x8` ou `this + 0x20` conforme `cat`):  
      i. Para cada entrada, chama `GCColorLibInfo::GetGreen255` e `FUN_180015cc0` para match de tipo/categoria.  
      ii. Se encontrado, chama `FUN_180015c00` para obter `GSharedObject<GCICCProfile>`, adquire referência (`AddRef`) e retorna.  
   c. Se nenhum match, lança `GCSimpleException` com código de erro correspondente (ex.: "No XYZ ICC profile has been defined").

5. **Conversão de cor via callback**  
   `GCCallbackConverter::ConvertColor(GTable<double> input, GTable<GFunction*> callbacks, GFunction* fn, int param, GTable<double>& output)`  
   a. Recebe tabela de valores de entrada (normalizados por canal).  
   b. Tabela de callbacks permite injetar transformações customizadas (ex.: device-link, spot-to-process).  
   c. Executa pipeline: para cada callback, aplica `fn(input[i])` acumulando em `output`.  
   d. Unidades de entrada/saída: double 0.0–1.0 (calibrated) ou 0–255 (device), conforme espaço de cor.

6. **Perfis padrão embutidos (strings .rdata)**  
   - `Enfocus XYZ Profile.icc` — perfil XYZ de referência (D50).  
   - `AdobeRGB1998.icc` — RGB calibrado.  
   - `WAN-IFRA/ISOcoated_v2_eci.icc` — CMYK ISO 12647-2 (FOGRA39/53).  
   - Mensagens de erro: "No XYZ ICC profile has been defined", "An ICC profile could not be read", "Invalid ICC profile".

7. **Dependências de runtime**  
   - `mscms.dll` (Windows Color System) — acesso a perfis do sistema.  
   - `lcms.dll` (Little CMS) — engine de transformação ICC v2/v4.  
   - Caminhos de busca: `%SystemColorFolder%`, `%LocalColorFolder%`, `%NetworkColorFolder%`, `%UserColorFolder%`, `%EnfocusResourceFolder%`, `\\SysWOW64\\`, `\\system32\\`.

8. **Tipos de cor suportados (enum ColorType)**  
   CMYK, RGB, Lab, Gray, Spot, DeviceN, MultiChannel — conforme `GCColorManipulationEnums::ColorType`.

9. **Intents de renderização**  
   Perceptual, RelativeColorimetric, Saturation, AbsoluteColorimetric — mapeados para `lcms` intents correspondentes.

## 5. Exceções

| Condição | Resultado |
|---|---|
| `Initialize()` não chamado antes de `GetInstance()` | `GCSimpleException` código interno; aplicação deve tratar no startup |
| `Initialize()` falha em `FUN_180027c40` ou `FUN_1800269b0` | Retorna `false`; subsistema de cor indisponível; mensagem "No Color Management support available" |
| `SetLevelICCProfile` com perfil NULL | Comportamento indefinido (não validado no binário); assume-se substituição por perfil vazio |
| `GetActiveICCProfile` sem match e `useCache == false` | Lança `GCSimpleException` com mensagem "No XYZ ICC profile has been defined" ou similar |
| Arquivo ICC inválido / não legível | Erro "An ICC profile could not be read" / "Invalid ICC profile"; conversão aborta |
| CMM engine solicitado indisponível | Erro "Color conversion was not possible because the requested CMM engine was not available"; fallback para lcms interno se possível |
| Número incorreto de canais de entrada para `ConvertColor` | Erro "Incorrect number of input values for color conversion"; nada é escrito em `output` |

## 6. Saída

- **Estado no documento**: Perfil ICC ativo por objeto (via `GCColorObject` com `GSharedObject<GCICCProfile>`), intent de renderização, black point compensation.
- **Gravado no PDF**: Perfis ICC embutidos (OutputIntent / DestOutputProfile), espaços de cor calibrados (ICCBased), tintas spot com alternate space, DeviceN com NChannel. Transformações de cor aplicadas aos valores de pixel/vetor não são revertíveis — o PDF contém o resultado convertido.
- **Visual**: Simulação de prova (soft proof) usa perfil ativo + intent; não altera dados do documento. Painel "Colors" exibe separações e perfil do documento sem modificar estado.
