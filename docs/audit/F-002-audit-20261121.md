## 6. Ressalvas

a) **`identifyRelevantSets()` retorna vazio.** O critério de “mark set
   relevante” (`ApplyRelevantMarkSets`, `0x180243F40`) não foi derivado; a
   seleção no clone é explícita. `TODO(F-002)` declarado em §9.1.

b) **Sem undo stack.** O processor não recebe `UndoStack` e não empilha comando;
   a operação apenas faz `setModified(true)` (`:298`). Na v240 a cópia roda
   dentro de `ActionGroupCreator` (ação única de undo). Declarado em §9.1.

c) **O clone não tem UI de Mark Set.** Nenhum arquivo em `src/ui` referencia
   `MarkSetProcessor` (verificado: 0 ocorrências); não há menu, action, dock ou
   diálogo. Declarado em §8.1 e §9.1.

d) **Caminho `.pdf` do loader não coberto por teste de sucesso.** O teste cobre
   `.pdf` inexistente, extensão inválida, `.artplus` corrompido e `.artplus`
   ponta a ponta; não há fixture PDF válida exercitando `PdfImporter` dentro de
   `loadMarkSetFile`. O caminho existe no código (`:196-209`), mas não é provado
   pelo teste desta feature.

e) **Marcas dinâmicas/`RelinkDynamicObjects` não modeladas.** Referência que sai
   do conjunto copiado é descartada (`mappedId` → `0`) em vez de religada;
   `DocumentMarks.Warning.MissingNamedObject`/`MissingPageBox` não são emitidos.
   `TODO(F-002)` em `:100-103`, declarado em §9.1.

f) **Camada de destino achatada.** O clone insere todos os objetos na camada de
   topo da página alvo (`targetLayerFor`), criando `Mark Set` se não houver
   camada; a v240 insere pelo `PageContent::Accept`. Declarado em §9.1.

g) **Build incremental.** `"configured": false`; não houve configure limpo. A
   auditoria não executou build/ctest por determinação explícita.

     v24.03.10017 pendente”, contradito pelo próprio `comportamental:

     superado.
