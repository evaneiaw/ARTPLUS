## Ressalvas Declaradas (para APROVADO COM RESSALVAS)

1. **UI histórica, ausente na v24** — A especificação (§3, §7.2, §9.1) e a evidência comportamental (CAP-20261121-02) confirmam: a ação "Selection Mark" **não existe** no ArtPro+ v24.03.10017. A UI implementada no clone (menu, atalho, toolbar, status) deriva **exclusivamente** de `docs/behavior/SelectionMark.md` (versão 25.0, histórica, sem `CAP-*`). Para um clone fiel da v24, **esta UI deve ser removida**.

2. **Cobertura funcional parcial** — Das 11 regras da spec (R1–R11), o clone implementa plenamente apenas:
   - R5 (escala) — com divergência de matriz (Qt vs `GOVChangeMatrix`)
   - R6 (rotação) — com divergência de matriz
   - R10 (estado de seleção) — arquitetura diferente (metadata vs `PDFObjectLayer`)
   - R11 (undo) — para operações implementadas
   - **Não implementados**: R1 (rubber-band), R2 (SetRect/SetHitType), R3 (sobreposição caixas), R4 (regiões GeoMapper), R7 (flip), R8 (clone), R9 (predicado)
   - Isso é **coerente** com a spec: o clone implementa a "ferramenta de UI Selection Mark" (objeto único com handles), não os operadores genéricos de seleção/transformação do DLL.

3. **ADR não localizada** — Frontmatter da spec referencia `ADR-004`; arquivo esperado em `docs/architecture/ADR-004-selection-mark.md` **não existe**. A decisão de arquitetura não está registrada no local canônico.

4. **Clone mais restritivo que spec em E6** — `isSelectable()` rejeita camada oculta/bloqueada e `ClippingMask`/`OpacityMask` (linhas 41–44). A spec (§5, E6) diz explicitamente: *"Sem evidência. Nada nos 13 documentos desta passada verifica camada, lock ou tipo de máscara. A afirmação anterior da spec era inferência e foi rebaixada para §8"*. O clone adiciona validação **não comprovada na v24**.

5. **Token de gate válido e laudo fresco** — Token `E93C61C35F7B9D60CCDC551BD15B9FB95331CA306EE7CFBACB9367A1A8D80276` confere. Laudo criado **após** modificação de `src/color_management/color_lib_info.cpp` (13:01:17).
