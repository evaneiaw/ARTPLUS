## Comportamento bate com o Original
**CRITÉRIO BLOQUEADO AMBIENTAL (HASP)**: O CAP-20261121-02 documenta a conclusão negativa da UI de Selection Mark na v24.03.10017:

> "a ação 'Selection Mark' (e o próprio menu 'Marks') não existe nos menus `File`, `Object`, `Select` e `Prepress` nem entre os rótulos do ribbon da v24.03.10017. `Ctrl+Shift+S` está atribuído a `Save As...`."

O binário `PDFObjectActions.dll` **não contém strings de UI** para "Selection Mark", "Selection Mark ativo", nem atalhos. A spec (§3) documenta que a UI vem do histórico (docs/behavior/SelectionMark.md, versão 25.0, fora do fluxo ativo).

**Implementação do ArtPlus**: O clone implementa UI (menu "Marks > Selection Mark", atalho `Ctrl+Shift+S`, barra de status "Selection Mark ativo") com base na descrição histórica, **não** em captura comportamental da v24.0.
