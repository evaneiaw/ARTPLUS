# ArtPlus
Desenvolvimento independente de um editor profissional de pré-impressão inspirado no fluxo de trabalho do ArtPro+.

## Estrutura do Projeto
- `src/`: Código fonte.
- `docs/`: Documentação técnica.
- `rag/`: Base de conhecimento para o projeto.
- `.opencode/`: Configuração de agentes e skills.
- `tests/`: Suíte de testes.

## Missão
Criar um aplicativo desktop independente, robusto e profissional para edição de pré-impressão, seguindo padrões de engenharia reversa comportamental autorizada e desenvolvimento de alta qualidade em C++/Qt.
