## Recolor
- Versão: 24.03.10017
- Caminho na UI: Object > Recolor...
- Entrada: test_vector.pdf (Ctrl+A seleciona objetos)
- Passos:
  1. Ctrl+A para selecionar objetos.
  2. Acessar menu Object > Recolor...
  3. Diálogo "Recolor" abre (dimensões 756×429).
- Campos do diálogo:
  | Nome | Tipo | Default | Unidade | Faixa aceita |
  |---|---|---|---|---|
  | Modo de Ação | Lista | Remove Separations | N/A | [Remove, Replace, Convert] |
  | Lista de Separações | Lista | - | N/A | (Exibe: Cyan, Magenta, Yellow, Black, PANTONE 485 C) |
  | Botão Remove | Botão | - | - | - |
  | Botão Close | Botão | - | - | - |
- Saída observada: O diálogo permite a seleção de separações para remoção ou manipulação baseada no modo escolhido.
- Erros e limites:
  - Não há campos de "ICC Profile", "Rendering Intent" ou "Black Point Compensation" presentes no diálogo.
  - Painel "Colors" na toolbar exibe o perfil do documento e as separações.
  - Nota: Não existe menu "Color > Color Management" na v24.
